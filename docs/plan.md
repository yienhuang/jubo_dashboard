# 集團總覽首頁 — 規劃文件

## 頁面目標

提供集團層級的一頁式營運快照，讓管理者快速掌握服務人數、人力、財務、機構健康度的當前狀態與趨勢。

---

## 頁面佈局結構

```
┌─────────────────────────────────────────────────────────────┐
│  KPI 摘要卡片列（4 張橫排：服務人數 / 員工數 / 月營收 / 累計營收）  │
├────────────────────────────────┬────────────────────────────┤
│  服務人數趨勢圖（堆疊長條）         │  服務人數佔比（圓餅）         │
├────────────────────────────────┬────────────────────────────┤
│  員工人數趨勢圖（堆疊長條）        │  流動率趨勢圖（折線）         │
├────────────────────────────────┬────────────────────────────┤
│  營收占比（圓餅）                 │  營收月趨勢圖（複合）        │
├─────────────────────────────────────────────────────────────┤
│  機構健康度排名（Top 3 + Bottom 2，橫排 5 張卡片）              │
├─────────────────────────────────────────────────────────────┤
│  各機構概況列表（表格）                                         │
└─────────────────────────────────────────────────────────────┘
```

Grid 欄寬比例（MUI Grid，12 欄制）：

| 列 | 左側元件 | 左欄寬 | 右側元件 | 右欄寬 |
|----|---------|--------|---------|--------|
| 服務人數 | 服務人數趨勢圖 | 5 | 服務人數佔比 | 5 |
| 人力 | 員工人數趨勢圖 | 5 | 流動率趨勢圖 | 5 |
| 營收 | 營收占比 | 5 | 營收月趨勢圖 | 5 |

## 待確認事項

1. **頁面路由**：是否掛載在現有首頁路徑（`/`），還是另開 `/overview`？
2. **資料來源**：各指標是否已有對應 API？或先以 mock data 實作？
3. **健康度演算法**：健康度等級如何判定（前端算或後端提供）？構成等級的指標有哪些？
4. **流動率異常閾值**：多少 % 以上要醒目顯示？
5. **機構健康度排名**：Top 3 + Bottom 2 共 5 張，若機構不足 5 間如何處理？
6. **各機構列表**：是否需要分頁、排序、或篩選功能？
7. **照護比分母**：計算時納入哪些職類（全護理人員 / 僅照服員）？

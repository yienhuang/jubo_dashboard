## 頁面結構總覽

頁面頂層為水平 Tab，分為：

- **總覽**（全集團住宿彙總）

- **台中南屯長照分院**

各 Tab 內容皆為「區塊標題 + 標題下的白色卡片」結構，不再有子 Tab。

## Anchor Chips

每個 Tab 切換後，Tab 列下方顯示一排 Chips，對應該 Tab 內的各區塊，點擊後平滑捲動（smooth scroll）至對應區塊標題。

**總覽 Tab Chips：**
`總覽統計` `各機構占床率趨勢` `各機構整體服務營收`

**各機構 Tab Chips：**
`機構概覽` `住民動態` `住民結構` `財務狀況`
